Model 2 Results and Explanation
===============================

Project task
------------
Model 2 is the PyTorch CNN model for emotion classification. The goal is to classify face images into one of four emotion classes:

- angry
- happy
- sad
- surprise

This model follows the assignment requirement of using a deep learning library to build and train a CNN for image classification.


Dataset used
------------
The dataset was prepared from a public benchmark emotion dataset and organized into separate folders for each class. The images were resized to 512 x 512 x 3 and split into training, validation, and testing folders.

The original prepared dataset contains:

- Training images: 8410
- Validation images: 2402
- Test images: 1205

For the final CPU-feasible Model 2 experiment, we used a balanced subset based on 1000 images per class in total:

- Training images used: 2800 images
- Validation images used: 800 images
- Test images used: 400 images

This means the testing stage used 100 images per class.


Preprocessing
-------------
The following preprocessing steps were used:

- Resize each image to 512 x 512.
- Convert each image to a PyTorch tensor.
- Normalize using standard RGB mean and standard deviation values.
- During training only, light augmentation was added to improve generalization:
  - Random horizontal flip
  - Small random rotation
  - Small brightness and contrast changes

Validation and testing did not use random augmentation because they should measure the model on stable, unchanged images.


Model architecture
------------------
The CNN architecture follows the required Model 2 design:

- Conv1: 3 input channels to 32 filters, kernel size 3 x 3
- ReLU
- MaxPool2d with 2 x 2 kernel
- Conv2: 32 filters to 64 filters, kernel size 3 x 3
- ReLU
- MaxPool2d with 2 x 2 kernel
- Conv3: 64 filters to 64 filters, kernel size 3 x 3
- ReLU
- MaxPool2d with 2 x 2 kernel
- Conv4: 64 filters to 32 filters, kernel size 5 x 5
- ReLU
- Conv5: 32 filters to 16 filters, kernel size 7 x 7
- ReLU
- Flatten
- Fully connected hidden layer with 256 hidden features
- Sigmoid activation
- Final fully connected output layer with 4 output logits

Valid convolution was used because no padding was added to the convolution layers.

During training, CrossEntropyLoss was used. This is correct because the model outputs raw logits and the loss function internally handles the softmax operation.


Training settings
-----------------
The final Model 2 training settings were:

- Image size: 512 x 512
- Batch size: 8
- Epochs: 10
- Optimizer: Adam
- Learning rate: 0.0001
- Weight decay: 0.0001
- Label smoothing: 0.05
- Hidden features: 256
- Device used: CPU
- Loss function: CrossEntropyLoss
- Training samples: 2800
- Validation samples: 800

The best model was saved based on the highest validation accuracy.

Saved model path:
outputs/models/best_model2.pth

K-fold validation
-----------------
K-fold validation was also performed for Model 2.

Settings:

- K value: 4
- Epochs per fold: 1
- Batch size: 8
- Image size: 512 x 512
- Learning rate: 0.001
- Samples used in K-fold: 4000

A balanced subset of 1000 images per class was used for K-fold validation to satisfy the dataset requirement while keeping the experiment feasible on a CPU-only machine.

K-fold results:

- Fold 1 accuracy: 38.20%
- Fold 2 accuracy: 24.80%
- Fold 3 accuracy: 25.60%
- Fold 4 accuracy: 35.60%

Average K-fold accuracy:
31.05%

The K-fold score is lower than the final trained model result because each fold was trained for only 1 epoch to keep runtime manageable on CPU. The final Model 2 result is based on the full 10-epoch training run.
